# loose · 轻盈一点

一个无需安装依赖的个人减脂追踪网页，可在 Mac 浏览器中打开，也可通过 GitHub Pages 分享。

## 功能

- 首次使用 3 步设置身高、年龄、性别参考和活动水平；之后在右上角“设置”中调整。
- 今日面板展示估算热量预算、已摄入/剩余热量、蛋白质差额、本月目标差值、体重快记，以及近 7 日饮食和体重变化摘要。BMI 低于 18.5 时按估算维持量显示，不再扣除减脂差额。
- 饮食记录支持选择历史日期、常见食物搜索、克数换算、一键套餐、自定义套餐与自动整理的“我的常吃”。食物库营养值为近似值，品牌食品建议按包装标签记录。
- 食物库包含 80 种常见食材；搜索无匹配时可录入自定义食物。食物克数可直接点击修改，删除后可撤销；推荐会结合当天蛋白质缺口和剩余预算。
- 体重页可补记体重、体脂率和腰围；显示 BMI 状态、参考体重区间、近 7/30 天变化、体脂率趋势与 7 日移动平均。设置中可隐藏 BMI 分类。
- 身体指标说明按中国成人标准解释 BMI，并按年龄、性别展示亚洲研究样本中由 BMI 18.5/25/30 换算的体脂率估值；腰围可结合中国成人切点及腰高比参考理解。它们仅供筛查，不作诊断。
- 月目标页显示按身高估算的参考体重区间；目标可自行修改，跨月首次打开时可复盘并延续或调整。
- 设置中可导出或导入 JSON 备份，并提示上次导出时间；浏览器支持时可安装为主屏幕网页应用。
- 图表会随屏幕宽度调整；备份导入会校验体重、饮食、个人资料、自定义食物和套餐。服务工作线程采用网络优先并在离线时回退缓存；每次发版都会更换缓存版本。

## 打开

在 Finder 双击 `index.html`，使用 Safari 或其他现代浏览器打开即可。也可直接访问 [loose 网站](https://yuxin020802.github.io/loose/)。

桌面分享与备份：通过 GitHub Pages 网址分享给朋友；每位用户的数据只保存在自己的浏览器中。定期在“设置”中导出 JSON 可迁移或备份记录，导入会替换当前浏览器中的数据。Safari 可使用“文件 → 添加到程序坞”将网站作为桌面网页应用打开；支持 PWA 的浏览器也可从安装入口添加。

## 隐私与估算说明

个人资料、饮食和体重记录保存在当前浏览器的本地存储，不会上传到网站服务器；不同设备和浏览器之间不会自动同步。每日能量预算使用 Mifflin–St Jeor 静息能量预测方程与活动系数进行估算，再减去小幅参考差额。它不是代谢测量或医疗建议，个体实际需求可能不同。方程适用于一般成人参考；未成年人、孕期/哺乳期以及有特殊健康需要者不应依此制定减重计划。

食物库使用常见食物的近似营养值，实际结果会因品种、品牌、生熟状态和烹调方式变化。请优先参考包装营养标签，并把烹调油、饮料和调味品也计入。

方便面（熟、沥水）的参考值取自 [FSANZ 澳大利亚食物成分数据库 F006053](https://www.foodstandards.gov.au/science-data/food-nutrient-databases/afcd/search/food/F006053)：每 100 g 约 144 kcal、蛋白质 3.8 g；不同品牌和调味方式请以包装为准。
